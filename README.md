# 风口瞭望 · 行业趋势政策工作台

> 行业风口、政策查询、转行规划、远程工作、视频教程一站式 PWA 工作台

## 项目介绍

风口瞭望是一个面向职业规划和行业洞察的轻量级 Web 应用（PWA），聚合了行业趋势、政策文件、国际动态、城市对比、远程工作、视频教程等多维度信息，帮助用户快速了解各行业风口，做出更明智的职业选择。

项目基于纯前端技术构建，部署在 GitHub Pages 上，支持离线使用，可安装到手机主屏幕像原生 App 一样使用。

## 功能特性

- **行业风口**：实时追踪 AI、新媒体、低空经济、储能、银发经济等热门赛道
- **政策查询**：汇总国家级和地方级政策文件，支持按分类筛选
- **国际动态**：全球科技行业趋势与市场数据
- **城市对比**：17+ 城市的产业结构、生活成本、政策支持对比分析
- **远程工作**：远程招聘信息与远程工作平台汇总
- **视频教程**：AI 漫剧、副业变现、技能提升等精选视频
- **多主题切换**：5 种主题配色 + 护眼模式
- **双语支持**：中英文界面切换
- **PWA 支持**：可安装到主屏幕，离线可用
- **自动更新**：每日自动抓取最新数据

## 部署步骤

### 1. Fork 到自己的 GitHub

1. 点击页面右上角的 **Fork** 按钮
2. 选择你的 GitHub 账号，等待 Fork 完成

### 2. 开启 GitHub Pages

1. 进入你 Fork 后的仓库
2. 点击顶部 **Settings** 标签
3. 在左侧菜单找到 **Pages**
4. 在 **Build and deployment** 部分：
   - **Source** 选择 `Deploy from a branch`
   - **Branch** 选择 `main` / `(root)`
   - 点击 **Save**
5. 等待几分钟，页面上方会显示你的站点地址，格式类似：
   ```
   https://你的用户名.github.io/fengkou-liaowang/
   ```

### 3. 配置 Actions 权限（重要！）

为了让自动更新脚本能提交数据，需要配置 Actions 权限：

1. 进入仓库 **Settings**
2. 左侧菜单找到 **Actions** → **General**
3. 滚动到 **Workflow permissions** 部分
4. 选择 **Read and write permissions**
5. 勾选 **Allow GitHub Actions to create and approve pull requests**
6. 点击 **Save**

## 配置自动更新

### 工作原理

项目内置了 GitHub Actions 工作流，每天北京时间早上 8:00 自动运行：

1. 运行 `scripts/update_data.py` 脚本
2. 从各数据源抓取最新数据
3. 与现有数据合并去重
4. 如果有变化，自动 commit 并 push 到 main 分支
5. push 触发 GitHub Pages 重新部署

### 手动触发更新

你也可以随时手动触发更新：

1. 进入仓库 **Actions** 标签
2. 左侧选择 **自动更新数据**
3. 点击 **Run workflow** 按钮
4. 选择 `main` 分支，点击 **Run workflow**

### 自定义数据源

编辑 `scripts/update_data.py` 文件，可以：

- 添加/修改 RSS 源地址
- 调整每个数据源的抓取数量
- 添加新的数据类型
- 修改数据合并规则

## 手机添加到主屏幕（PWA 安装）

### iPhone / iPad (Safari)

1. 用 Safari 打开你的站点地址
2. 点击底部的 **分享** 按钮（方框带箭头的图标）
3. 向下滑动，找到并点击 **添加到主屏幕**
4. 输入名称（如"风口瞭望"），点击 **添加**
5. 返回主屏幕即可看到 App 图标

### Android (Chrome)

1. 用 Chrome 打开你的站点地址
2. 点击右上角的 **三个点** 菜单
3. 点击 **安装应用** 或 **添加到主屏幕**
4. 按照提示完成安装
5. 安装后可以像普通 App 一样从桌面打开

### 安装后的优势

- 全屏体验，没有浏览器地址栏
- 支持离线使用（Service Worker 缓存）
- 启动速度更快
- 独立的应用图标

## 数据来源说明

| 数据类型 | 主要来源 | 更新频率 |
|---------|---------|---------|
| 行业趋势 | 36氪、虎嗅、爱范儿等科技媒体 RSS | 每日 |
| 政策文件 | 国务院政策文件库、各地方政府门户 | 每日 |
| 国际动态 | TechCrunch、The Verge 等国际媒体 | 每日 |
| 远程工作 | 电鸭社区等远程工作平台 | 按需 |
| 视频教程 | Bilibili 搜索 API | 每日 |
| 城市数据 | 各地政府公开数据、统计局 | 稳定，不常更新 |

> **注意**：数据来源于公开网络，仅供参考。脚本具有容错能力，部分数据源不可用时会保留现有数据，不影响使用。

## 本地开发

```bash

git clone https://github.com/你的用户名/fengkou-liaowang.git
cd fengkou-liaowang

# 启动本地服务器（Python）
python3 -m http.server 8080

# 然后在浏览器访问 http://localhost:8080
```

# 运行更新脚本
python3 scripts/update_data.py
